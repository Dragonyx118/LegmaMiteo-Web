API Pubbliche

Interfaccia RESTful aperta e gratuita per integrare i dati aggregati della rete nei vostri sistemi software e modelli previsionali locali. Nessuna API key richiesta in lettura.

GET /api/v1/stations/{station_id}/live

Restituisce le ultime metriche istantanee inviate dai sensori di una specifica stazione attiva.

{
  "station_id": "station-001",
  "timestamp": "2026-06-19T11:33:00Z",
  "sensors": {
    "temperature": 23.4,
    "humidity": 56.0,
    "pressure": 1012.3,
    "wind_speed": 12.5
  }
}
GET /api/v1/stations/{station_id}/history

Serie storica delle misurazioni in una finestra temporale, utile per analisi e grafici. Parametri opzionali: from, to, interval.

GET /api/v1/stations/station-001/history?from=2026-06-18T00:00:00Z&to=2026-06-19T00:00:00Z

{
  "station_id": "station-001",
  "points": [
    { "timestamp": "2026-06-18T00:00:00Z", "temperature": 18.1, "pressure": 1014.0 },
    { "timestamp": "2026-06-18T00:30:00Z", "temperature": 17.9, "pressure": 1013.8 }
  ]
}
GET /api/v1/stations

Elenca tutte le stazioni attive nella rete con posizione geografica e stato corrente.

{
  "stations": [
    { "id": "station-001", "lat": 45.4642, "lon": 9.1900, "status": "online" }
  ]
}
GET /health

Endpoint leggero di health-check usato anche dal sito per mostrare lo stato online/offline della rete in tempo reale.

{ "status": "ok" }
