Dettagli di Progetto

Architettura Hardware & Ingegneria

Firmware ed Edge Computing

Sviluppato in ambiente C++/Arduino nativo per microcontrollori ESP32, il firmware implementa algoritmi di campionamento a basso rumore ed elaborazione dei dati direttamente a bordo (Edge Computing). Gestione avanzata dei cicli di deep-sleep per ridurre i consumi a micro-ampere.

Topologia Radio LoRa Mesh

Il protocollo wireless integrato permette alle stazioni isolate di configurarsi automaticamente come nodi ripetitori. I dati saltano da una stazione all'altra in modalità peer-to-peer fino a raggiungere il gateway Internet più vicino, espandendo la copertura anche in valli non coperte da rete cellulare.

Scocca e Certificazione Stampa 3D

Tutti i componenti strutturali includono file CAD pronti per la stampa 3D in materiali resistenti ai raggi UV (ASA/PETG). Lo schermo solare ventilato (Radiation Shield) è ottimizzato idrodinamicamente per proteggere i sensori termici senza falsare le letture microclimatiche.

PUBLIC REST API

Accesso Libero ai Dati

Tutti i dati meteorologici raccolti sono accessibili pubblicamente tramite endpoint REST standard. Nessun token richiesto per la lettura.

# Richiesta ultimi dati registrati dal nodo station-001
GET /data/station-001/latest

# Struttura del payload di risposta
{
  "temperature": 29.7,
  "humidity": 61.8,
  "pressure": 1017.6,
  "wind_speed": 29.2
}
