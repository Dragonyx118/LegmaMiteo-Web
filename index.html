FEATURES

Built for
Real Science

🧩

Modular Design

Base unit plus 8 swappable expansion modules — from air quality to lightning detection, soil moisture to snow depth.

📡

Dual Connectivity

WiFi primary connection with LoRa mesh fallback for remote mountain or rural deployments with no internet access.

☀️

Solar Powered

10W panel with LiFePO4 battery and MPPT controller — fully autonomous, no grid required, runs indefinitely.

🔔

Smart Alerts

Telegram notifications for critical conditions — pressure drops, lightning nearby, PM2.5 spikes, high temperature.

🌐

Open REST API

Public API to access all station data in real time. CC BY-NC 4.0 licensed — free for research and education.

⚡

Storm Detection

AS3935 lightning sensor with pressure delta analysis for early detection of severe convective events and supercells.
